# React Native Kakao Map

Native Kakao Maps for Android and iOS, implemented with Expo Modules. Requires Expo 52+, React Native 0.76+, and the New Architecture. Core is not required.

See the [installation and API guide](https://rnkakao.mjstudio.net/docs/map/intro).

Kakao Maps SDK versions: Android 2.15.2 and iOS 2.12.19. Use a native development or Release build; Expo Go and web maps are unsupported. Android map runtime requires an ARM device or emulator.
