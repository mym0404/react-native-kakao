# React Native Kakao Cert

`@react-native-kakao/cert` exposes Kakao certification login, abbreviated signatures, and device-local signing sessions. Certification requires an approved Kakao app and server integration.

Install it with `@react-native-kakao/core` and `@react-native-kakao/user`. Native signing is available on Android and iOS; web supports the JavaScript SDK's certification authorization redirect.

See the [usage and setup guide](https://rnkakao.mjstudio.net/docs/cert/intro).
