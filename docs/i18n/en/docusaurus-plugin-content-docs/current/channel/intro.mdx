# Getting Started with Kakao Channel

## Before You Begin

Make sure to install the dependencies for the `Core` package by referring to the [official installation guide](/docs/install-core). Also, complete the [platform-specific configurations](/docs/install-android).

## Getting Started

The `channel` package allows you to interact with KakaoTalk channels.

KakaoTalk Channel (formerly Plus Friends) is a service for sharing service updates with KakaoTalk users through messages and posts.

KakaoTalk Channel can send marketing messages to friends. Friends are users who have added the KakaoTalk channel as a friend.

To reduce costs and improve effectiveness, you can send KakaoTalk Channel messages to friend groups selected by gender, age, location, grade, and other user information.

Refer to the [Official Documentation](https://developers.kakao.com/docs/latest/ko/kakaotalk-channel/common) for more details.
