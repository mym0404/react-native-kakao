# Threading

## Threads Used by the API

All APIs explicitly run on the **Main Thread**.

Kakao Native SDK functions use callbacks, which also run on the Main Thread.

Most logic runs on the Main Thread to prevent potential errors, and the package's functions are mainly utilities ported from the Native SDK that do not perform heavy computations.

The implementation can change if future performance work requires it.

:::tip
In iOS Native Modules, `requireMainQueueSetup` can increase app startup time and is unnecessary, so it is not used.
:::
