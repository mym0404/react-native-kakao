# Expo Settings

## Expo Settings

In Expo, you can use preconfigured [config plugins](https://docs.expo.dev/config-plugins/introduction/).

:::tip
If you need config plugin settings beyond those this package provides,
refer to the [Android Settings](/docs/install-android) and [iOS Settings](/docs/install-ios) to write those settings yourself.
:::

## Installation of expo-build-properties

```shell
npx expo install expo-build-properties
```

## app.json Settings

The initial configuration has few settings; add the required `android` and `ios` settings as you use other packages.

```json title='app.json'
"plugins": [
  [
    "expo-build-properties",
    {
      "android": {
        "extraMavenRepos": [
          "https://devrepo.kakao.com/nexus/content/groups/public/"
        ]
      }
    }
  ],
  [
    "@react-native-kakao/core",
    {
      "nativeAppKey": "{{native app key}}",
      "android": {
        ...
      },
      "ios": {
        ...
      }
    }
  ]
]
```

## (Optional) Android Obfuscation Settings

When R8 code shrinking is enabled for an Android release build, the autolinked `@react-native-kakao/core` library supplies the Kakao rules automatically. No rule injection is needed for Kakao. You can use [expo-build-properties](https://docs.expo.dev/versions/latest/sdk/build-properties/) for rules required by other libraries or app code. See [Android Setup](/docs/install-android) if you link the core library manually.

## (Optional) Web Platform Support

Follow the instructions in the [Web Settings](/docs/install-web).
