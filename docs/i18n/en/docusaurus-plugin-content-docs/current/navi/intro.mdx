# Getting Started with Kakao Navigation

## Before You Begin

Make sure to install the dependencies for the `Core` package by referring to the [official installation guide](/docs/install-core). Also, complete the [platform-specific configurations](/docs/install-android).

## Getting Started

The `navi` package provides Kakao Navigation functions.

It opens the Kakao Navi app to request navigation or share a destination.

Refer to the [Official Documentation](https://developers.kakao.com/docs/latest/ko/kakaonavi/common) for more details.

## Kakao Navi installation status

After initializing the SDK, call `isKakaoNaviInstalled()` to check whether Kakao Navi is installed. This only queries availability; it does not open the app or its installation page.

```tsx
import { isKakaoNaviInstalled } from '@react-native-kakao/navi';

const isInstalled = await isKakaoNaviInstalled();
```

Android returns the Kakao SDK's installation check. iOS checks whether it can open the `kakaonavi-sdk` URL scheme and requires the query scheme in [Navi setup](/docs/navi/intro-ios). Web returns `false` because it cannot inspect installed apps; use `navigateTo` and `shareTo` to request a launch from mobile web.
