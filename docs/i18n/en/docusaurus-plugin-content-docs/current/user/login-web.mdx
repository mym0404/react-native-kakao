# Kakao Login (Web)

Web login requires extra steps because it redirects the user to another page using a redirect URI.

:::tip
All APIs except for login can be used similarly to those in [Kakao Login](/docs/user/login).
:::

## Logging In

Use Kakao Login to register users, log in, request additional consent, and obtain agreement to service terms.

## Adding Redirect URI in Kakao Console

Add a Redirect URI in the Kakao Login section of the Kakao Console.

![feat](https://raw.githubusercontent.com/mym0404/image-archive/master/202405030144548.webp)

:::warning
The example uses port 80 in a development environment. You should register the required Redirect URI for both development and release environments.
:::

```tsx
const { code } = useGlobalSearchParams<{ code?: string }>();
const accessTokenIssued = useRef(false);
useEffect(() => {
  const go = async () => {
    const { accessToken } = await issueAccessTokenWithCodeWeb({
      code: code!,
      redirectUri: 'http://localhost',
    });
    setAccessTokenWeb(accessToken);
    accessTokenIssued.current = true;
  };

  if (code && !accessTokenIssued.current) {
    go();
  }
}, [code]);
```

## Step 1: Retrieve Authorization Code via Search Parameter from the Redirected Page after Simple Login

Calling the `login()` function redirects the user to the Kakao login page.

On the web platform, you must pass the `web` object.

Other options outside the `web` object are ignored.

For example, `prompt` is available both inside and outside the `web` object, but the web platform uses only the `prompt` inside the `web` object.

```tsx
import { login } from '@react-native-kakao/user';

...

login({
  web: {
    redirectUri: 'http://localhost',
    prompt: ['select_account'],
  },
})
```

:::danger Dangerous
The `redirectUri` registered in the console must match the values used when calling `login` and `issueAccessTokenWithCodeWeb` for login to work.
:::

Refer to the [Official Documentation](https://developers.kakao.com/docs/latest/ko/kakaologin/js#login) for detailed information on the parameters.

## Step 2: Issue Access Token with Authorization Code

Use `issueAccessTokenWithCodeWeb()` to exchange the authorization code for an Access Token.

Once you have the Access Token, pass it to the `setAccessTokenWeb()` function.

The example below completes login in Expo Router using `code` from the search parameter.

```tsx
const { code } = useGlobalSearchParams<{ code?: string }>();
const accessTokenIssued = useRef(false);
useEffect(() => {
  const go = async () => {
    const { accessToken } = await issueAccessTokenWithCodeWeb({
      code: code!,
      redirectUri: 'http://localhost',
    });
    setAccessTokenWeb(accessToken);
    accessTokenIssued.current = true;
  };

  if (code && !accessTokenIssued.current) {
    go();
  }
}, [code]);
```

:::tip TIP
This code is an example. You must retrieve `code` from the search parameter, then call `issueAccessTokenWithCodeWeb` and `setAccessTokenWeb` in that order.
:::

Refer to the [Official Documentation](https://developers.kakao.com/docs/latest/ko/kakaologin/rest-api#request-token-request-body) for detailed information on the parameters.

### Response

The API returns token information in a `Promise`.

The response includes the following:

```tsx
{
  tokenType: string;
  accessToken: string;
  idToken?: string;
  expiresIn: number; // unix
  refreshToken: string;
  refreshTokenExpiresIn: number; // unix
  scope?: string;
};
```
