# Service Terms

`serviceTerms()` retrieves the service terms the user has agreed to. On Android, iOS, and web, pass `result: 'app_service_terms'` to include enabled terms the user has not agreed to, or pass `tags` to retrieve specific registered terms.

[Official documentation](https://developers.kakao.com/docs/en/kakaologin/rest-api#service-terms)

This API requires Kakao Sync and a logged-in user. It reads consent information; it does not request consent or revoke it.

## Usage

```tsx
import { serviceTerms } from '@react-native-kakao/user';

const agreedTerms = await serviceTerms();
const allTerms = await serviceTerms({ result: 'app_service_terms' });
const selectedTerms = await serviceTerms({
  result: 'app_service_terms',
  tags: ['service_2020_0218'],
});
```

Replace the sample tag with a tag registered for your app.

| Option | Type | Behavior |
| --- | --- | --- |
| `result` | `'agreed_service_terms' \| 'app_service_terms'` | Defaults to agreed terms. `app_service_terms` includes all enabled terms. |
| `tags` | `string[]` | Filters by registered service terms tags. Web sends the comma-separated value required by the JavaScript SDK. |

## Response

Returns `Promise<KakaoServiceTerms[]>`. An absent terms list in a successful response becomes an empty array. Authentication errors and unregistered tags reject the promise with Kakao's error.

```tsx
export type KakaoServiceTerms = {
  tag: string;
  agreedAt?: number;
  agreed: boolean;
  required: boolean;
  revocable: boolean;
};
```

`agreedAt` is a Unix timestamp in seconds when present. Terms retrieved with `app_service_terms` use the same response type, including `agreed` for each term.
