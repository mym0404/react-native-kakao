# Service Terms Agreement

## Retrieve Service Terms Agreement Information

[Official Documentation](https://developers.kakao.com/docs/latest/ko/kakaologin/ios#terms)

Use `serviceTerms()` to retrieve service terms consent information.

:::warning
This feature is only available for apps using Kakao Sync.
:::

The response type is `Promise<KakaoServiceTerms[]>`.

The type is defined as follows:

```tsx
export type KakaoServiceTerms = {
  tag: string;
  agreedAt?: number;
  agreed: boolean;
  required: boolean;
  revocable: boolean;
};
```

### Example

```tsx
serviceTerms()
```
