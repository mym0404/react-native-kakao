# iOS Configuration

## Setting Up URL Handling for KakaoTalk Login

Refer to the [Official Documentation](https://developers.kakao.com/docs/latest/ko/kakaologin/ios#before-you-begin-setting-for-kakaotalk) for the required KakaoTalk login setup.

Follow the [instructions](https://developers.kakao.com/docs/latest/ko/ios/getting-started#project-plist) to add KakaoTalk to the app's Allowlist so the app can launch KakaoTalk, and set up a [custom URL scheme](https://developers.kakao.com/docs/latest/ko/documentation-guideline/glossary#%E3%85%8B) to return to the service app.

During KakaoTalk login, the service app opens KakaoTalk and the user returns after pressing [Agree and Continue] or cancelling the login.

To complete Kakao login when the user returns from KakaoTalk to the service app, add the following code to `AppDelegate.mm`.

```objc
#import "AppDelegate.h"

// highlight-start
#import <React/RCTLinkingManager.h>
#import <RNCKakaoUser/RNCKakaoUserUtil.h>
// highlight-end

@implementation AppDelegate

...

// highlight-start
// Linking API
-  (BOOL)application:(UIApplication *)application openURL:(NSURL *)url options:(NSDictionary<UIApplicationOpenURLOptionsKey,id> *)options {

  // Handling logic in this app if the URL scheme is from KakaoTalk.
  if([RNCKakaoUserUtil isKakaoTalkLoginUrl:url]) {
    return [RNCKakaoUserUtil handleOpenUrl:url];
  }

  return [super application:application openURL:url options:options] || [RCTLinkingManager application:application openURL:url options:options];
}
// highlight-end

...

@end

```

:::note
For more details or examples using Swift or `SceneDelegate`, refer to the [Official Documentation](https://developers.kakao.com/docs/latest/ko/kakaologin/ios#before-you-begin-setting-for-kakaotalk).
:::
