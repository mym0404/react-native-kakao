# Get User Profile

`me()` retrieves the user profile on Android, iOS, and web. Image URLs use HTTPS by default. Pass `secureResource: false` to request HTTP URLs.

The response is as follows:

```tsx
Promise<KakaoUser>
```

The `KakaoUser` type is defined as:

```tsx
export type KakaoUser = {
  id: number;
  hasSignedUp?: boolean | null;
  uuid?: string | null;
  email: string;
  name?: string | null;
  nickname: string;
  profileImageUrl: string;
  thumbnailImageUrl: string;
  isDefaultImage?: boolean | null;
  phoneNumber?: string | null;
  ageRange?: string | null;
  birthday?: string | null;
  birthdayType?: string | null;
  isLeapMonth?: boolean | null;
  birthyear?: string | null;
  gender?: string | null;
  isEmailValid: boolean;
  isEmailVerified: boolean;
  isKorean?: boolean;
  ageRangeNeedsAgreement?: boolean;
  birthdayNeedsAgreement?: boolean;
  birthyearNeedsAgreement?: boolean;
  emailNeedsAgreement?: boolean;
  genderNeedsAgreement?: boolean;
  isKoreanNeedsAgreement?: boolean;
  phoneNumberNeedsAgreement?: boolean;
  profileNeedsAgreement?: boolean;
  nameNeedsAgreement?: boolean;
  profileImageNeedsAgreement?: boolean;
  profileNicknameNeedsAgreement?: boolean;
  legalName?: string | null;
  legalNameNeedsAgreement?: boolean | null;
  legalBirthDate?: string | null;
  legalBirthDateNeedsAgreement?: boolean;
  legalGender?: 'female' | 'male' | null;
  legalGenderNeedsAgreement?: boolean | null;
  connectedAt?: number;
  synchedAt?: number;
};
```

### Example

```tsx
me()
```

## Profile metadata

These fields use the same names on Android, iOS, and web. Values that Kakao does not provide are `null`; `false` remains a value rather than an absence marker.

| Field | Meaning | Availability |
| --- | --- | --- |
| `isDefaultImage` | `true` means the default profile image; `false` means an image registered by the user. | The user has consented to the profile image scope. |
| `isLeapMonth` | Whether the birthday falls in a leap month. | The user has consented to the birthday scope. |
| `uuid` | The user's own ID in KakaoTalk friend information, distinct from the service user ID in `id`. | The app has KakaoTalk friends or messaging permission. |

For example, `user.isDefaultImage === false` identifies an image registered by the user. `null` does not establish whether the image is a default. See the [user information response](https://developers.kakao.com/docs/en/kakaologin/rest-api#req-user-info-response) for availability conditions.

## Legal identity information

Partner apps with prior approval from Kakao can retrieve identity-verified names, birth dates, and genders with `me()`. App permission and user consent are required. Values that Kakao does not provide are `null`. This information must not replace identity verification.

| Field | Meaning | Format |
| --- | --- | --- |
| `legalName` | Identity-verified legal name | String |
| `legalBirthDate` | Identity-verified legal birth date | `yyyyMMdd` |
| `legalGender` | Identity-verified legal gender | `female` or `male` |

Each corresponding `NeedsAgreement` flag indicates whether the information can be provided after user consent. `true` requires additional consent; `false` does not guarantee that the value is available. See [partner user information](https://developers.kakao.com/docs/ko/kakaologin/confidential-user-info) for the requirements.

## Query options

| Option | Type | Behavior |
| --- | --- | --- |
| `secureResource` | `boolean` | Whether image URLs use HTTPS. Defaults to `true`; `false` requests HTTP URLs. |

Pass `secureResource: false` only when you need HTTP image URLs. This option changes the returned image URLs; the API request still uses HTTPS.

```tsx
const user = await me({ secureResource: false });
```

## Manual connection state

`hasSignedUp` reports whether a user has completed connection to a manual connection app. `false` means pending, `true` means connected, and `null` means Kakao omitted the field. An omitted value in an automatic connection app does not mean the user is signed out.

Connect a pending user with [manual signup](./signup.mdx).
