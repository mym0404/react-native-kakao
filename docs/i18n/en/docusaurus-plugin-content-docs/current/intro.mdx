# Getting Started

## React Native Kakao

<img alt={'logo'} src={require('@site/static/img/logo.png').default} width={256} />

[React Native Kakao](https://github.com/mym0404/react-native-kakao) manages Kakao SDKs for React Native in a monorepo for consistency.

## Compatibility {#compatibility}

| Library version | Minimum iOS requirements | Minimum Android requirements | Kakao SDK versions |
| --- | --- | --- | --- |
| v2 | iOS 13 | API 23 | iOS 2.22.0 / Android 2.20.1 |
| v3 | iOS 15.1 | API 24 | iOS 2.29.0 / Android 2.25.0 |

v3 is not released yet and requires React Native 0.76 or later with the New Architecture enabled. Expo integrations require SDK 52 or later. If your React Native or Expo version requires a higher OS version, use that requirement.

## Migrating to v3 {#migration}

See the [v3 migration guide](./migration-v3) for the changes required when updating from v2 to v3.

## Highlights

- **No version conflicts**
  - Consistently managed native SDK versions prevent version conflicts.
- **Consistent logic across platforms**
  - The same JS code runs the same logic on Android, iOS, and Web.
- **APIs designed for developer experience**
  - All APIs put developer experience (DX) first.
- **TypeScript support**
  - Includes first-class support for **TypeScript**
- **API references and setup guides**
  - Includes full API references, installation documentation, detailed guides, and FAQs
- **Supported platforms**
  - Supports **Android, iOS, Web, and Expo**.
- **SDK error handling**
  - All SDK errors are passed to JS clearly and consistently across platforms.

## How APIs and Documentation Are Maintained

:::tip
This document does not cover all details about the basic configuration or APIs of the Kakao SDK.
We recommend checking the official Kakao SDK documentation for the features you need.

This documentation covers the minimum setup and API usage needed to use this package.
:::

API usage and module structure follow the [Kakao SDK](https://developers.kakao.com/docs/latest/ko/ios/getting-started).

Function and module names generally follow the iOS documentation, with `Core` used in place of `Common`.

![kakao sdk](https://raw.githubusercontent.com/mym0404/image-archive/master/202404211418541.webp)

For example, the `User` module in the image above corresponds to `@react-native-kakao/user`.

:::info
Always check the relevant official documentation for each API's required permissions and settings, and its behavior and errors when those conditions are not met.

-  [Android Official Documentation](https://developers.kakao.com/docs/latest/ko/android/getting-started)
-  [iOS Official Documentation](https://developers.kakao.com/docs/latest/ko/ios/getting-started)
:::
