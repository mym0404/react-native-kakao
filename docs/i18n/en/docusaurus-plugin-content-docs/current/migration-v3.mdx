# Migrating from v2 to v3

Before updating to v3, check the minimum React Native, Expo, iOS, and Android requirements in the [compatibility table](./intro#compatibility).

If your v2 project uses the Old Architecture, enable React Native's New Architecture.

## Removed APIs

Remove any uses of the following APIs:

- Friend picker option `title`
- Login prompt `UnifyDaum`
- Profile response field `ciNeedsAgreement`

Do not automatically replace `UnifyDaum` with another login prompt. Specify only the prompts required by your login flow.

## Blocked-account error code

If your code compares the error object's `code`, replace the previous platform-specific value with `BlockedAccount`.

| Platform | v2              | v3               |
| -------- | --------------- | ---------------- |
| Android  | `BlockedAction` | `BlockedAccount` |
| iOS      | `Blocked`       | `BlockedAccount` |
