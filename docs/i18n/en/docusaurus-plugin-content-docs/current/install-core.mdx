# Core Package Installation

## Core Package Installation

This project is a monorepo, and all packages depend on `@react-native-kakao/core`.

Install it with one of the commands below:

<Tabs>
  <TabItem value="npm" label="NPM" default>
    ```shell
    npm install --save @react-native-kakao/core
    ```
  </TabItem>
  <TabItem value="yarn" label="Yarn">
    ```shell
    yarn add @react-native-kakao/core
    ```
  </TabItem>
  <TabItem value="expo" label="Expo">
    ```shell
    npx expo install @react-native-kakao/core
    ```
  </TabItem>
</Tabs>

Other packages declare `core` as a peer dependency, so you must always install `@react-native-kakao/core` alongside them.
