# Core Package Installation

## Core Package Installation

Kakao service packages depend on `@react-native-kakao/core`. The independent [`map` Expo Module](/docs/map/intro) does not require Core.

Install it with one of the commands below:

<Tabs>
  <TabItem value="npm" label="NPM" default>
    ```shell
    npm install --save @react-native-kakao/core
    ```
  </TabItem>
  <TabItem value="yarn" label="Yarn">
    ```shell
    yarn add @react-native-kakao/core
    ```
  </TabItem>
  <TabItem value="expo" label="Expo">
    ```shell
    npx expo install @react-native-kakao/core
    ```
  </TabItem>
</Tabs>

The `user`, `share`, `social`, `channel`, and `navi` packages declare `core` as a peer dependency. Install `@react-native-kakao/core` alongside these packages.
