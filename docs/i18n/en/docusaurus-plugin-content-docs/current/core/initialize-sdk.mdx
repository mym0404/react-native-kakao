# Initialize the SDK

## Initialize the SDK

When the app starts, call `initializeKakaoSDK` in a file such as `index.js` or `App.tsx` before using any Kakao SDK.

```tsx title='index.js'
import { initializeKakaoSDK } from '@react-native-kakao/core';

initializeKakaoSDK('{{ native app key }}');
```

:::info
You must call this function before calling any Kakao API.
:::

## Web Platform

If your app supports Web, you must also pass the JavaScript key and REST API key in the `web` option.

```ts
import { initializeKakaoSDK } from '@react-native-kakao/core';

Core.initializeKakaoSDK('{{ native app key }}', {
  web: {
    javascriptKey: '{{ javascript key }}',
    restApiKey: '{{ rest api key }}',
  },
});
```
