# Getting Android Key Hash

## Getting Android Key Hash

This utility function retrieves the key hash in each Android environment.

```tsx title='index.js'
import { getKeyHashAndroid } from '@react-native-kakao/core';

getKeyHashAndroid().then(console.log);
```

:::info
In a debug environment where the console is visible, you can check the result with `console.log` as shown above.

In a release environment, you can display the key in a component such as `Text` to retrieve it accurately.

You can also extract the key hash manually without this utility by following the [Official Documentation](https://developers.kakao.com/docs/latest/ko/android/getting-started#before-you-begin-add-key-hash).
:::
