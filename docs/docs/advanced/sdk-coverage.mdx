# Native SDK 지원 범위

Android·iOS Kakao SDK의 공개 서비스 API를 Core, User, Social, Channel, Share, Navi, Cert 패키지로 제공해요. 웹은 JavaScript SDK와 사용자 토큰용 REST API가 지원하는 기능을 제공해요. 앱 전환, 로컬 키·세션, SDK 전용 URL 생성처럼 브라우저에서 같은 동작을 제공할 수 없는 기능은 아래에 구분했어요.

구현 여부와 실제 성공 응답의 검증 여부는 달라요. 이용 승인을 받은 앱이나 설치된 카카오 앱이 필요한 성공 경로는 [검증 범위](#검증-범위)에 남겨 뒀어요.

## SDK 버전과 대조 범위

네이티브 기본 버전은 [`packages/core/package.json`의 `sdkVersions`](https://github.com/mym0404/react-native-kakao/blob/main/packages/core/package.json)에서 관리해요. SDK 버전을 덮어쓰면 이 표와 실제 동작이 달라질 수 있어요. 실행 중인 버전은 [`getKakaoSDKInfo()`](/docs/core/initialize-sdk)로 확인해요.

| SDK                  | 버전                                                                   | 범위                                                              |
| -------------------- | ---------------------------------------------------------------------- | ----------------------------------------------------------------- |
| Android              | `2.25.1`                                                               | Common, Auth, User, Talk, Friend, Share, Template, Navi, Cert     |
| iOS                  | `2.29.0`                                                               | 같은 서비스의 공개 SDK 제품                                       |
| 제휴 친구 피커       | Android `1.0.0`, iOS 리비전 `83917aaf996e5d4072e73b681507228fbd967d42` | 제휴 친구 선택 옵션                                               |
| JavaScript 검증 환경 | `2.8.4`                                                                | 웹 SDK 스크립트는 [웹 설정](/docs/install-web)에 따라 앱에서 설치 |

이 대조는 위 SDK의 공개 서비스 메서드, 입력 옵션, 응답 필드를 대상으로 해요. SDK 내부 전용 메서드, 지원이 종료된 API, 같은 기능의 콜백·비동기 오버로드는 별도 JS API로 중복 제공하지 않아요. SDK 클라이언트와 토큰 저장소 교체도 노출하지 않아요. 푸시·톡캘린더·관리자용 REST API나 별도 카카오맵 SDK는 이 네이티브 SDK 대조 범위에 포함하지 않아요. 카카오 API 전체의 지원 여부는 [공식 지원 범위](https://developers.kakao.com/docs/ko/getting-started/scope-of-support)에서 확인해요.

## 기능별 공개 API

표에서 플랫폼을 따로 표시한 기능을 제외하면 Android·iOS를 모두 지원해요. 웹 열은 같은 기능을 브라우저에서 호출했을 때의 동작이에요.

### Core

| 기능             | 공개 API·옵션                                                                       | 웹                                                                                 |
| ---------------- | ----------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| SDK 초기화       | [`initializeKakaoSDK`](/docs/core/initialize-sdk), `customScheme`, `loggingEnabled` | JavaScript 키·REST API 키로 초기화해요. 네이티브 스킴·로깅 옵션은 적용하지 않아요. |
| 버전·초기화 상태 | [`getKakaoSDKInfo`](/docs/core/initialize-sdk)                                      | `version`, `isInitialized`를 반환해요. 네이티브 설정 필드는 반환하지 않아요.       |
| Android 키 해시  | [`getKeyHashAndroid`](/docs/core/get-android-keyhash)                               | `undefined`를 반환해요. Android 전용이에요.                                        |

기본 템플릿은 피드·리스트·위치·커머스·텍스트·캘린더 여섯 종류예요. 각 종류에 공유, 나에게 보내기, 친구에게 보내기 함수를 제공해요. 예를 들어 피드는 `shareFeedTemplate`, `sendFeedTemplateToMe`, `sendFeedTemplateToFriends`를 사용해요.

| 기능                                 | 공개 API·옵션                                                                                                                                   | 웹                                                                                    |

| 기본·사용자 정의 템플릿 공유         | [기본 템플릿](/docs/share/share-default-feed), [`shareCustomTemplate`](/docs/share/share-custom), 템플릿 인자·서버 콜백 인자·브라우저 대체 공유 | JavaScript SDK로 공유해요.                                                            |
| URL 스크랩 공유                      | [`shareScrapTemplate`](/docs/share/share-scrap): 기본·사용자 정의 템플릿                                                                        | 지원해요.                                                                             |

| 공유 대상 피커 설정                  | [`pickerSettings`](/docs/share/share-custom)                                                                                                    | JavaScript SDK에 전달해요. 네이티브 카카오톡의 표시 효과는 아래 검증 범위를 확인해요. |

## 응답 계약

타임스탬프는 Unix 초, 유효 시간은 초 단위예요. SDK 응답의 키 이름과 enum 표현을 공개 TypeScript 타입에 맞춰 변환해요. 사용자 동의나 앱 권한이 없어 받은 `null`·미제공 필드를 성공 데이터로 채우지 않아요.

기존 공유·메시지 함수의 성공 반환값은 플랫폼마다 다를 수 있어요. 이 값으로 발송 결과를 판단하지 않고, 각 함수의 반환 타입을 확인해요. 친구에게 보내기는 기본적으로 성공 UUID 배열을 반환하고, 상세 옵션을 사용하면 `{ successfulReceiverUuids, failureInfos }`를 반환해요. 실제 메시지 수신, 앱 전환 완료, 웹 리다이렉트 이후의 인증 결과는 각 흐름에서 따로 확인해야 해요.

비동기 데이터 조회·변경 API는 SDK·HTTP 오류를 Promise 거부로 전달해요. `isLogined`와 `navigateTo`·`shareTo`처럼 상태나 실행 여부를 반환하는 함수는 토큰 조회·SDK 실행 실패를 `false`로 반환하기도 해요. JavaScript 입력 검사는 Promise를 반환하기 전에 동기적으로 오류를 던질 수 있어요. 각 함수의 반환 타입과 오류 처리는 해당 사용 문서를 따라요.

## 검증 범위

다음은 2026년 10월 21일까지 기록한 실제 응답·실행 검증 이력이에요. 최신 커밋의 RN 0.76 빌드와 RN 0.88 빌드·E2E 결과는 각 PR에서 따로 확인해요. 빌드와 입력·응답 변환 검사를 통과해도, 앱 권한이나 설치 조건이 없는 성공 경로까지 검증한 것은 아니에요. 각 PR의 `Confidence level`은 해당 변경에서 확인한 범위를 나타내요.

로그인한 계정으로 확인한 API 성공 응답에는 Android `2.25.0`과 JavaScript `2.7.1`에서 얻은 결과도 포함돼요. 버전을 올린 뒤 다시 확인한 범위는 [SDK 업데이트](https://github.com/mym0404/react-native-kakao/pull/174)와 후속 PR에 기록돼 있어요. 아래 표에서 로그인이 필요한 모든 기능의 성공 경로를 Android `2.25.1`·JavaScript `2.8.4`에서 재실행한 것은 아니에요.

| 기능                       | 확인한 결과                                                                                                              | 남은 성공 경로·조건                                                                                                           |
