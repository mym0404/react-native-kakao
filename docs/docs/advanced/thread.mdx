# 스레드

## API가 동작하는 스레드

모든 API는 명시적으로 **Main Thread**에서 동작합니다.

Kakao Native SDK의 함수는 콜백 방식으로 동작하며 콜백도 Main Thread에서 실행됩니다.

이 패키지는 발생할 수 있는 에러를 방지하기 위해 모든 로직을 Main Thread에서 실행합니다.

이 패키지의 함수는 대부분 Native SDK를 포팅한 유틸리티 함수이므로 무거운 연산을 하지 않는다고 판단했습니다.

추후 성능 개선이 필요하다고 논의되면 이 동작은 언제든지 수정될 수 있습니다.

:::tip
iOS Native Module의 `requireMainQueueSetup`은 앱 시작을 지연시킬 수 있고 필요하지도 않으므로 사용하지 않습니다.
:::
