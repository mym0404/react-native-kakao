# 리액트 네이티브 카카오 시작하기

## React Native Kakao

<img alt={'logo'} src={require('@site/static/img/logo.png').default} width={256} />

[React Native Kakao](https://github.com/mym0404/react-native-kakao)는 React Native용 카카오 SDK를 모노레포로 일관되게 관리합니다.

## 호환성 {#compatibility}

| 라이브러리 버전 | iOS 최소 요건 | Android 최소 요건 | Kakao SDK 버전 |
| --- | --- | --- | --- |
| v2 | iOS 13 | API 23 | iOS 2.22.0 / Android 2.20.1 |
| v3 | iOS 15.1 | API 24 | iOS 2.29.0 / Android 2.25.1 |

v3는 아직 배포되지 않았으며 React Native 0.76 이상과 새 아키텍처가 필요합니다. Expo에서는 SDK 52 이상을 사용합니다. 사용하는 React Native·Expo가 더 높은 OS 버전을 요구하면 해당 요건을 따릅니다.

## v3 마이그레이션 {#migration}

v2에서 v3로 업데이트할 때 필요한 변경 사항은 [v3 마이그레이션 안내](/docs/migration-v3)를 확인합니다.

## 주요 기능 {#highlights}

- 네이티브 SDK 버전을 일관되게 관리해 버전 충돌을 방지합니다.
- 같은 JavaScript 코드로 Android, iOS, 웹에서 같은 로직을 실행합니다.
- 개발자가 사용하기 쉬운 API를 제공합니다.
- TypeScript를 지원합니다.
- API 참조, 설치 문서, 상세 가이드와 자주 묻는 질문을 제공합니다.
- Android, iOS, 웹과 Expo를 지원합니다.
- SDK 오류를 플랫폼마다 일관된 방식으로 JavaScript에 전달합니다.

## API와 문서가 관리되는 법

:::tip
이 문서는 카카오 SDK의 기본 설정과 API의 모든 세부 사항을 다루지는 않습니다.
필요한 기능은 카카오 SDK의 공식 문서에서 확인하는 것을 권장합니다.

이 패키지를 사용하는 데 필요한 최소 설정과 API 사용법을 다룹니다.
:::

API 사용법과 모듈 구조는 [카카오 SDK](https://developers.kakao.com/docs/latest/ko/ios/getting-started)의 구조를 따릅니다.

함수와 모듈 이름은 대개 iOS 문서를 따르며 `Common`만 `Core`로 바꿔 사용합니다.

![kakao sdk](https://raw.githubusercontent.com/mym0404/image-archive/master/202404211418541.webp)

예를 들어, 위 이미지에 `User` 모듈이 있기 때문에 `@react-native-kakao/user`가 있습니다.

:::info
각 API에 필요한 권한과 설정, 조건을 충족하지 않았을 때의 동작과 에러는
항상 관련 공식 문서에서 확인하세요.

- [Android 공식 문서](https://developers.kakao.com/docs/latest/ko/android/getting-started)
- [iOS 공식 문서](https://developers.kakao.com/docs/latest/ko/ios/getting-started)
:::
