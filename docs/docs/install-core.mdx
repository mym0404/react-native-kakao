# 공통 패키지 설치

## 공통 패키지 설치

카카오 서비스 패키지는 `@react-native-kakao/core`에 의존해요. 독립적인 Expo Module인 [`map` 패키지](/docs/map/intro)는 Core 없이 설치해요.

아래 명령으로 설치할 수 있습니다.

<Tabs>
  <TabItem value="npm" label="NPM" default>
    ```shell
    npm install --save @react-native-kakao/core
    ```
  </TabItem>
  <TabItem value="yarn" label="Yarn">
    ```shell
    yarn add @react-native-kakao/core
    ```
  </TabItem>
  <TabItem value="expo" label="Expo">
    ```shell
    npx expo install @react-native-kakao/core
    ```
  </TabItem>
</Tabs>

`user`, `share`, `social`, `channel`, `navi`는 `core`를 peer dependency로 선언하므로 `@react-native-kakao/core`를 함께 설치해요.
