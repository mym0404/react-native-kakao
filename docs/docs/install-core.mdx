# 공통 패키지 설치

## 공통 패키지 설치

이 프로젝트는 모노레포로 구성되며 모든 패키지는 `@react-native-kakao/core` 패키지에 의존합니다.

아래 명령으로 설치할 수 있습니다.

<Tabs>
  <TabItem value="npm" label="NPM" default>
    ```shell
    npm install --save @react-native-kakao/core
    ```
  </TabItem>
  <TabItem value="yarn" label="Yarn">
    ```shell
    yarn add @react-native-kakao/core
    ```
  </TabItem>
  <TabItem value="expo" label="Expo">
    ```shell
    npx expo install @react-native-kakao/core
    ```
  </TabItem>
</Tabs>

다른 패키지는 `core` 패키지를 peer dependency로 선언하므로 `@react-native-kakao/core`를 항상
함께 설치해야 합니다.
