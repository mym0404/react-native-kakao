# iOS 설정

## 카카오톡 로그인 URL 핸들링 설정

[공식 문서](https://developers.kakao.com/docs/latest/ko/kakaologin/ios#before-you-begin-setting-for-kakaotalk)

카카오톡으로 로그인하려면 반드시 설정해야 합니다.

[설정](https://developers.kakao.com/docs/latest/ko/ios/getting-started#project-plist)을 참고해 앱에서 카카오톡을 실행할 수 있도록 앱 실행 허용 목록(Allowlist)에 카카오톡을 등록하고
서비스 앱으로 돌아올 때 사용할 [커스텀 URL 스킴](https://developers.kakao.com/docs/latest/ko/documentation-guideline/glossary#%E3%85%8B)을 설정합니다.

카카오톡으로 로그인할 때는 서비스 앱에서 카카오톡으로 이동한 뒤 사용자가 [동의하고 계속하기] 버튼 또는
로그인 취소 버튼을 누르면 서비스 앱으로 돌아옵니다.

카카오톡에서 서비스 앱으로 돌아왔을 때 카카오 로그인을 완료하려면
`AppDelegate.mm` 파일에 다음 코드를 추가합니다.

```objc
#import "AppDelegate.h"

// highlight-start
#import <React/RCTLinkingManager.h>
#import <RNCKakaoUser/RNCKakaoUserUtil.h>
// highlight-end

@implementation AppDelegate

...

// highlight-start
// Linking API
- (BOOL)application:(UIApplication *)application openURL:(NSURL *)url options:(NSDictionary<UIApplicationOpenURLOptionsKey,id> *)options {

  // 카카오톡에서 전달된 URL scheme면 이 앱에서 핸들링하는 로직입니다.
  if([RNCKakaoUserUtil isKakaoTalkLoginUrl:url]) {
    return [RNCKakaoUserUtil handleOpenUrl:url];
  }

  return [super application:application openURL:url options:options] || [RCTLinkingManager application:application openURL:url options:options];
}
// highlight-end

...

@end

```

:::note
더 자세한 내용이나 Swift 혹은 `SceneDelegate`를 사용하는 예제는 [공식 문서](https://developers.kakao.com/docs/latest/ko/kakaologin/ios#before-you-begin-setting-for-kakaotalk)를 참고하세요.
:::
