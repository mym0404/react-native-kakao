# 서비스 약관 동의

## 서비스 약관 동의 내역 얻어오기

[공식 문서](https://developers.kakao.com/docs/latest/ko/kakaologin/ios#terms)

`serviceTerms()`로 서비스 약관 동의 내역을 조회할 수 있습니다.

:::warning
카카오싱크를 사용하는 앱에서만 사용할 수 있습니다.
:::

응답은 다음과 같습니다.

```tsx
Promise<KakaoServiceTerms[]>
```

타입은 다음과 같습니다.

```tsx
export type KakaoServiceTerms = {
  tag: string;
  agreedAt?: number;
  agreed: boolean;
  required: boolean;
  revocable: boolean;
};
```

### 예시

```tsx
serviceTerms()
```
