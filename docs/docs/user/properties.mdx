# 사용자 프로퍼티 저장

`updateProfile({ properties })`로 앱에 등록된 사용자 정의 프로퍼티에 문자열 값을 저장할 수 있습니다. Android, iOS, 웹에서 성공하면 반환값 없이 완료하며 SDK 오류가 발생하면 `Promise`를 거부합니다.

호출하기 전에 카카오디벨로퍼스의 **카카오 로그인 > 고급 > 사용자 프로퍼티**에서 키를 등록해야 합니다. 사용자는 로그인한 상태여야 합니다.

```tsx
import { updateProfile } from '@react-native-kakao/user';

await updateProfile({ properties: { custom_key: 'value' } });
```

이 API는 앱별 사용자 프로퍼티를 저장합니다. 사용자의 카카오계정 프로필, 닉네임, 프로필 이미지는 수정하지 않습니다.

필요한 설정과 오류는 카카오의 [사용자 프로퍼티 저장 문서](https://developers.kakao.com/docs/en/kakaologin/rest-api#update-profile)에서 확인할 수 있습니다.
