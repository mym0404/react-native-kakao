# 카카오 로그인, 유저 관리 시작하기

## 시작하기 전에

[`Core`패키지에 대한 의존성을 설치](/docs/install-core)하고 관련 [플랫폼별 설정](/docs/install-android)을 완료해야 합니다.

## 시작하기

`user` 패키지는 카카오 로그인과 관련 기능을 담습니다.

[공식 문서](https://developers.kakao.com/docs/latest/ko/kakaologin/common)를 참고하세요.

## 설치하기

<Tabs>
  <TabItem value="npm" label="NPM" default>
    ```shell
    npm install --save @react-native-kakao/user
    ```
  </TabItem>
  <TabItem value="yarn" label="Yarn">
    ```shell
    yarn add @react-native-kakao/user
    ```
  </TabItem>
  <TabItem value="expo" label="Expo">
    ```shell
    npx expo install @react-native-kakao/user
    ```
  </TabItem>
</Tabs>

## 콘솔 설정하기

카카오 로그인과 유저 API를 구현하기 전에 카카오 개발자 콘솔에서 추가 설정을 해야 합니다.

[공식 문서](https://developers.kakao.com/docs/latest/ko/kakaologin/prerequisite)를 참고하세요.
