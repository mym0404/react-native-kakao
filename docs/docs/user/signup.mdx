# 수동 연결

`signup()`은 카카오 로그인 후 연결 대기 중인 사용자를 앱에 연결합니다. Android, iOS, 웹에서 사용할 수 있으며, 카카오와 협의해 로그인 시 앱 자동 연결을 비활성화한 앱에서만 호출합니다.

## 사용 조건

카카오디벨로퍼스의 **카카오 로그인 > 로그인 시 앱 자동 연결** 설정이 `사용 안함`이어야 합니다. 메뉴가 보이지 않으면 자동 연결을 사용하는 앱이므로 이 API가 필요하지 않습니다.

먼저 `login()`으로 로그인하고 서비스에서 필요한 가입 절차를 마친 뒤 호출합니다. 이미 연결된 사용자에게 호출하면 카카오가 `-102` 오류를 반환합니다.

수동 연결 앱은 로그인 후 24시간 안에 연결을 완료해야 합니다. 기한이 지나면 카카오가 연결 대기 사용자를 가입 미완료자로 분류하고 연결을 해제합니다.

## 사용법

사용자 프로퍼티를 저장하지 않으려면 인자 없이 호출합니다. 성공하면 `Promise<void>`가 완료됩니다.

```tsx
import { me, signup } from '@react-native-kakao/user';

const user = await me();
if (user.hasSignedUp === false) {
  await signup();
}
```

`me().hasSignedUp`은 연결 대기 상태에서 `false`, 연결 완료 후 `true`입니다. 카카오가 값을 제공하지 않으면 `null`이므로, 값이 없는 상태를 연결 대기로 판단하지 않습니다.

## 사용자 프로퍼티 저장

연결과 함께 프로퍼티를 저장하려면 `properties`에 문자열 키와 값을 전달합니다. 키는 카카오디벨로퍼스에 미리 등록해야 합니다.

```tsx
await signup({ properties: { membership: 'basic' } });
```

| 인자 | 타입 | 필수 | 의미 |
| --- | --- | --- | --- |
| `properties` | `Record<string, string>` | 아니요 | 연결하면서 저장할 사용자 프로퍼티 |

회원번호가 필요하면 연결 후 `me().id`를 조회합니다. 요청에 실패하면 반환된 `Promise`가 거부됩니다.

자세한 조건과 오류는 [카카오 수동 연결 문서](https://developers.kakao.com/docs/ko/kakaologin/rest-api#signup)를 참고하세요.
