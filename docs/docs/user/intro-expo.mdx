# Expo 설정

## Android, iOS 설정

`app.json`에 다음과 같이 추가합니다.

```json title='app.json'
[
  "@react-native-kakao/core",
  {
    "nativeAppKey": "{{native app key}}",
    "android": {
// highlight-next-line
      "authCodeHandlerActivity": true
    },
    "ios": {
// highlight-next-line
      "handleKakaoOpenUrl": true
    }
  }
],
```

`ios.handleKakaoOpenUrl`은 AppDelegate와 Expo의 SceneDelegate에서 카카오톡 로그인 복귀 URL을 처리합니다.
직접 구현한 SceneDelegate는 URL 콜백을 AppDelegate로 전달해야 합니다.

Expo SDK 57(57.0.23 이상)에서 Scene을 사용하려면 `expo-build-properties`의 `ios.enableSceneSupport`를 켜세요.
SDK 58 이상은 기본으로 지원합니다. [Scene 설정 가이드](https://github.com/expo/fyi/blob/main/ios-scene-lifecycle.md)

Expo Router에서 카카오 로그인 복귀 시 `Unmatched Route`가 나타나면,
[`+native-intent.tsx`](https://docs.expo.dev/router/advanced/native-intent/)의 `redirectSystemPath`로 복귀 URL을 앱의 화면 경로에 연결하세요.
