# Web 설정
## Web 설정

React Native Kakao는 Native와 Web 플랫폼에서 같은 수준의 개발자 경험을 제공합니다.

설정에 관한 자세한 내용은 [Kakao SDK 문서](https://developers.kakao.com/docs/latest/ko/javascript/getting-started)에서 확인할 수 있습니다.

## 카카오 JavaScript SDK 설치

[다운로드](https://developers.kakao.com/docs/latest/ko/javascript/download) 페이지에서 최신 버전의 카카오 SDK를 `index.html`의 `head`에 삽입하여 설치합니다.

```html
<!DOCTYPE html>
<html>
<head>
...
  <script src="https://t1.kakaocdn.net/kakao_js_sdk/{{Version}}/kakao.min.js"
          integrity="{{integrity}}"
          crossorigin="anonymous"></script>
</head>

<body>
...
</body>
</html>

```

:::tip
Expo에서는 `npx expo customize` 명령으로 `index.html`을 수정할 수 있습니다.

[Expo 문서](https://docs.expo.dev/more/expo-cli/#customizing)
:::

## Web API에 대하여

Web API의 내부 구현은 Android, iOS 플랫폼과 다를 수밖에 없습니다.

API 응답은 플랫폼 간에 일관되고 이름도 모두 동일하지만 Web 전용 API와 인자도 있습니다.

예를 들어 로그인 시 사용하는 `redirectUri`가 Web 전용 인자입니다.

Web에서만 사용하거나 필요한 API는 함수 이름 뒤에 `Web`이 붙습니다.

예를 들어 `Core.setAccessTokenWeb()`이 있습니다.

Web 전용 인자는 모두 함수 인자의 `web` 필드에 전달합니다.

`core` 패키지의 SDK 초기화 함수는 다음과 같습니다.

```tsx
export async function initializeKakaoSDK(
  appKey: string,
  // eslint-disable-next-line @typescript-eslint/no-unused-vars
  options: { web?: { javascriptKey: string; restApiKey: string } },
)
```

이 함수는 필요한 Web 전용 인자를 `web` 객체로 받습니다.

:::warning
Web을 지원하지 않는다면 `web` 인자를 지정할 필요가 없으며 `Web`으로 끝나는 API도 호출하지 말아야 합니다.

`web` 인자가 없으면 API는 Web에서도 기본 인자로 동작합니다.
:::
