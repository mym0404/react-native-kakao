# SDK 초기화하기

## SDK 초기화하기

앱이 실행되면 Kakao SDK를 사용하기 전에 `index.js`나 `App.tsx` 등에서 `initializeKakaoSDK` 함수를 호출합니다.

```tsx title='index.js'
import { initializeKakaoSDK } from '@react-native-kakao/core';

initializeKakaoSDK('{{ native app key }}');
```

:::info
모든 카카오 API를 호출하기 전에 반드시 이 함수를 먼저 호출해야 합니다.
:::

## Web 플랫폼

Web을 지원한다면 `web` 옵션에 JavaScript 키와 REST API 키를 함께 전달해야 합니다.

```ts
import { initializeKakaoSDK } from '@react-native-kakao/core';

Core.initializeKakaoSDK('{{ native app key }}', {
  web: {
    javascriptKey: '{{ javascript key }}',
    restApiKey: '{{ rest api key }}',
  },
});
```
