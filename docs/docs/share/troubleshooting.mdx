# Troubleshooting & FAQ

[공식 문서](https://developers.kakao.com/docs/latest/ko/message/common)

## 앱이 비정상 종료돼요

메시지 타입의 인자를 확인하세요.

`templateArgs`나 `serverCallbackArgs`는 **꼭 문자열 키와 문자열 값을 객체로** 전달해야 합니다.

## 카카오톡, 브라우저가 실행은 되지만 4002 에러 등 메시지를 보낼 수 없어요

메시지 타입 인자에 문제가 있는 경우입니다.

전달한 인자가 TypeScript 타입 정의에 맞는지, 빈 배열 등을 전달하지 않았는지 확인하세요.

템플릿 아이디나 캘린더 템플릿 아이디는 카카오 콘솔에서 미리 설정해야 합니다.

## 링크 실행 우선순위에 대하여

Android와 iOS의 실행 인자가 가장 먼저 적용되며 이후 `mobileWebUrl`, `webUrl`이 있으면 실행됩니다.

## 카카오톡 메시지 API는 지원하지 않나요?

아직 카카오톡 공유 API만 지원합니다.

## 이미지가 제대로 보이지 않아요

모든 이미지는 최소 200px x 200px 이상이며 2MB 이하여야 합니다.

## 버튼을 누르면 내 웹페이지로 이동하지 않아요

카카오 콘솔에서 웹 플랫폼과 웹사이트 URL을 미리 등록해야 합니다.
