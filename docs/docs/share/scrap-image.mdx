# 이미지 URL 스크랩 {#scrap-image}

`scrapImage()`는 공개된 URL의 이미지를 카카오 이미지 서버에 저장하고 이미지 정보를 반환합니다. Android, iOS, 웹의 응답 형식은 같습니다. 카카오 SDK를 초기화한 뒤 호출해야 하며, 사용자 로그인은 필요하지 않습니다.

```tsx
import { scrapImage } from '@react-native-kakao/share';

const { infos } = await scrapImage({ imageUrl: 'https://example.com/image.png' });

const content = {
  imageUrl: infos.original.url,
  imageWidth: infos.original.width,
  imageHeight: infos.original.height,
  title: 'Image',
  link: { webUrl: 'https://example.com' },
};
```

`secureResource`의 기본값은 `true`이며 HTTPS 이미지 URL을 반환합니다. HTTP URL이 필요하면 `false`로 설정합니다. 웹에서는 JavaScript SDK가 이 옵션을 제공하지 않으므로, 반환된 카카오 CDN URL의 프로토콜을 요청한 값에 맞춥니다.

응답에는 이미지 URL, 형식, 크기 정보가 포함됩니다.

```ts
type KakaoImageUploadResult = {
  infos: {
    original: {
      url: string;
      contentType: string;
      length: number; // Bytes
      width: number; // Pixels
      height: number; // Pixels
    };
  };
};
```

카카오 서버에서 접근할 수 있는 5 MB 이하의 이미지만 사용할 수 있습니다. 저장한 이미지는 100일 동안 보관합니다. 이 API는 이미지를 저장하며 메시지를 발송하지 않습니다.

[이미지 스크랩 공식 문서](https://developers.kakao.com/docs/en/kakaotalk-share/android-link#scrap-image)를 참고하세요.
