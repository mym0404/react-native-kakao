# 카카오 공유 시작하기

## 시작하기 전에

[`Core`패키지에 대한 의존성을 설치](/docs/install-core)하고 관련 [플랫폼별 설정](/docs/install-android)을 완료해야 합니다.

## 시작하기

`share` 패키지는 카카오톡 공유와 메시지 발송 기능을 제공합니다.

[공식 문서](https://developers.kakao.com/docs/latest/ko/message/common)를 참고하세요.

![image](https://raw.githubusercontent.com/mym0404/image-archive/master/202404271646217.webp)

:::tip
위 이미지는 카카오톡이 설치되지 않은 환경에서 웹 브라우저로 공유하는 화면입니다.

카카오톡이 설치된 기기에서는 카카오톡으로 공유합니다.
:::

## 설치하기

<Tabs>
  <TabItem value="npm" label="NPM" default>
    ```shell
    npm install --save @react-native-kakao/share @react-native-kakao/social
    ```
  </TabItem>
  <TabItem value="yarn" label="Yarn">
    ```shell
    yarn add @react-native-kakao/{share,social}
    ```
  </TabItem>
  <TabItem value="expo" label="Expo">
    ```shell
    npx expo install @react-native-kakao/share @react-native-kakao/social
    ```
  </TabItem>
</Tabs>

## 콘솔 설정하기

카카오 공유와 카카오 메시지를 구현하기 전에 카카오 개발자 콘솔에서 추가 설정을 해야 합니다.

[공식 문서](https://developers.kakao.com/docs/latest/ko/message/prerequisite)를 참고하세요.

## 카카오톡 공유 가능 여부

SDK를 초기화한 뒤 `isKakaoTalkSharingAvailable()`로 기기에서 카카오톡 공유를 실행할 수 있는지 조회합니다. 조회만 하며 카카오톡이나 브라우저를 열지 않습니다.

```tsx
import { isKakaoTalkSharingAvailable } from '@react-native-kakao/share';

const isAvailable = await isKakaoTalkSharingAvailable();
```

Android와 iOS는 카카오 SDK의 확인 결과를 반환합니다. iOS에는 [공통 iOS 설정](/docs/install-ios)의 앱 조회 스킴이 필요합니다. 웹은 기기의 앱 설치 여부를 확인할 수 없어 `false`를 반환합니다. 웹 공유 기능은 기존 공유 API로 사용할 수 있습니다.
