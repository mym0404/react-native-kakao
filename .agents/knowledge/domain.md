# Domain Glossary

- **Kakao service**: A Kakao capability exposed to a React Native app, such as login, sharing, or navigation.
- **Native module**: A published package that connects the JavaScript API to Kakao SDK behavior on a supported platform.
- **Config plugin**: The Expo integration that writes app configuration needed by native Kakao SDK flows during prebuild.
- **Platform parity**: The same public API behavior across Android, iOS, and web, including method names, optional values, and result shapes.
